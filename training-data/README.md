# Training Data Collection

This directory contains training data for ML-based cleanup feature.

## Directory Structure

```
training-data/
├── raw/                          # Raw HTML files (original + cleaned pairs)
│   ├── <example-id>-original.html
│   └── <example-id>-cleaned.html
└── labeled-examples.json         # Generated labeled dataset (auto-generated)
```

## Data Collection Process

### Step 1: Extract Article Container

1. Visit a webpage with an article
2. Activate reader mode in the extension
3. Open browser DevTools and inspect the reader mode container
4. Copy the HTML of the article container (the `<article class="sr-article">` element)
5. Save it as `training-data/raw/<example-id>-original.html`

**Note:** The "original" HTML here is actually the article container *after* extraction but *before* cleanup. This is what `extractArticle()` returns.

### Step 2: Manually Clean the HTML

1. Open the original HTML file
2. Manually remove all non-article elements:
   - Ads (`c-adDisplay`, `data-ad` attributes)
   - Navigation elements
   - Related content blocks
   - Video players
   - Author cards (if not part of article)
   - Footer elements
   - Any other noise/distractions
3. Keep only the core article content:
   - Headings (h1, h2, etc.)
   - Paragraphs
   - Images (with captions)
   - Lists
   - Article metadata (if relevant)
4. Save the cleaned version as `training-data/raw/<example-id>-cleaned.html`

### Step 3: Generate Labels Automatically

Run the label generation script:

```bash
npm run generate-labels <example-id>
```

Example:
```bash
npm run generate-labels cnet-galaxy-chip
```

This will:
- Compare original and cleaned HTML
- Automatically generate labels for each element (keep/remove)
- Append to `training-data/labeled-examples.json`

### Step 4: Validate Training Data

After collecting multiple examples, validate the dataset:

```bash
npm run validate-training-data
```

This will:
- Check data format and quality
- Show statistics (total labels, keep/remove ratio)
- Identify issues or inconsistencies
- Provide recommendations

## Example Workflow

```bash
# 1. Collect HTML pairs manually (save to training-data/raw/)
#    - example1-original.html
#    - example1-cleaned.html

# 2. Generate labels
npm run generate-labels example1

# 3. Repeat for more examples
npm run generate-labels example2
npm run generate-labels example3

# 4. Validate when done
npm run validate-training-data
```

## Label Format

Each labeled example contains:

```json
{
  "id": "example-id",
  "url": "https://example.com/article",  // Optional
  "originalHtml": "...",
  "cleanedHtml": "...",
  "labels": [
    {
      "selector": "#element-id",
      "xpath": "//div[@id='element-id']",
      "keep": true,
      "autoGenerated": true
    }
  ]
}
```

## Tips

1. **Start with 50 examples** - This provides a good baseline for training
2. **Diverse sources** - Collect examples from different websites (news sites, blogs, etc.)
3. **Consistent cleaning** - Use the same criteria for what to keep/remove
4. **Validate regularly** - Run validation after every 10-15 examples
5. **Review labels** - Check that auto-generated labels make sense (especially for edge cases)
